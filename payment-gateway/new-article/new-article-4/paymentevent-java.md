Этот класс представляет собой тип данных для события, связанного с платежом. Он используется для передачи информации о платеже, такой как ID платежа, заказ, статус и сумма, а также временная метка события.

#### \#Пакет:

```
package com.example.payment.gateway.domain;
```

#### \#Импорты:

```
import java.time.Instant;
```

#### \#Описание:

-  `PaymentEvent` использует `record` -- новый тип данных, введённый в Java 14 для упрощения создания неизменяемых объектов с автоматически сгенерированными методами `toString()`, `equals()`, `hashCode()` и конструктором.

---

### \#Поля:

1. **paymentId**:

   ```
   Long paymentId;
   ```

   Идентификатор платежа.

2. **orderId**:

   ```
   Long orderId;
   ```

   Идентификатор заказа, с которым связан этот платёж.

3. **status**:

   ```
   PaymentStatus status;
   ```

   Статус платежа. Это перечисление, которое описывает текущее состояние платежа, например, "в процессе", "успешно" или "неудачно".

4. **amount**:

   ```
   Long amount;
   ```

   Сумма платежа.

5. **ts (timestamp)**:

   ```
   Instant ts;
   ```

   Время, когда произошло событие. Это поле хранит метку времени события в формате `Instant`, который представляет точный момент времени.

---

### \#Резюме:

`PaymentEvent` -- это неизменяемый тип данных, представляющий событие, связанное с платёжной операцией. Он включает важную информацию о платеже, такую как его ID, ID заказа, статус, сумма и временная метка события. Этот класс удобен для использования в функциональном и асинхронном программировании, а также идеально подходит для передачи данных в системе, где важна неизменяемость и простота работы с данными.

Этот класс представляет собой перечисление для различных состояний платежа. Он используется для отслеживания и управления статусами платежей в процессе их обработки.

#### \#Пакет:

```
package com.example.payment.gateway.domain;
```

#### \#Описание:

`PaymentStatus` -- это перечисление, которое определяет возможные состояния платежа. Это помогает точно указать текущий статус каждого платежа в системе и выполнять соответствующие действия в зависимости от состояния.

---

### \#Значения перечисления:

1. **INIT**:

   ```
   INIT;  // заказ создан, средств ещё нет
   ```

   Статус, когда заказ был создан, но ещё не произведено резервирование средств.

2. **AUTHORIZED**:

   ```
   AUTHORIZED;  // деньги зарезервированы
   ```

   Статус, когда деньги были зарезервированы, но ещё не списаны с карты или счета клиента.

3. **CAPTURED**:

   ```
   CAPTURED;  // средства списаны полностью
   ```

   Статус, когда средства были успешно списаны с карты клиента в полном объеме.

4. **PARTIALLY_CAPTURED**:

   ```
   PARTIALLY_CAPTURED;  // частичное списание
   ```

   Статус, когда средства были списаны частично, например, если клиент решил оплатить часть суммы сразу.

5. **FAILED**:

   ```
   FAILED;  // ошибка при авторизации
   ```

   Статус, когда произошла ошибка при попытке авторизации средств. Например, ошибка при проверке карты или недостаточно средств.

6. **REFUNDED**:

   ```
   REFUNDED;  // возврат
   ```

   Статус, когда средства были возвращены клиенту, например, при отмене заказа или возврате товара.

---

### \#Резюме:

`PaymentStatus` -- это перечисление, которое определяет возможные статусы платежа в процессе его обработки. Эти статусы включают различные стадии, такие как создание заказа, авторизация, захват средств, частичное списание, ошибка и возврат средств. Использование перечислений помогает чётко управлять состояниями платежей и упрощает обработку данных в системе.

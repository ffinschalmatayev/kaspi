Этот класс представляет собой тип данных для запроса на захват средств. Он используется для передачи данных о сумме, которую необходимо захватить при выполнении операции захвата платежа.

#### \#Пакет:

```
package com.example.payment.gateway.dto;
```

#### \#Описание:

`CaptureRequest` является типом данных `record`, который был введён в Java 14 для упрощения создания неизменяемых объектов. Этот тип данных содержит только одно поле -- сумму, которую нужно захватить при выполнении операции захвата платежа.

---

### \#Поля:

1. **amount**:

   ```
   Long amount;
   ```

   Сумма, которую необходимо захватить. Это поле будет содержать число, которое указывает, сколько средств должно быть списано при захвате платежа.

---

### \#Резюме:

`CaptureRequest` -- это неизменяемый тип данных, который используется для захвата части или всей суммы платежа. Включает в себя одно поле `amount`, которое указывает, какую сумму нужно захватить. Этот класс удобен для передачи данных в рамках операций захвата средств в платежной системе.

Этот класс представляет собой тип данных для запроса на создание платежа. Он используется для передачи данных, таких как идентификатор заказа и сумма, которые необходимы для инициирования платёжной операции.

#### \#Пакет:

```
package com.example.payment.gateway.dto;
```

#### \#Описание:

`PaymentRequest` -- это тип данных `record`, который был введён в Java 14 для упрощения создания неизменяемых объектов. Этот тип данных содержит два поля: `orderId` и `amount`, которые используются для инициирования платежа.

---

### \#Поля:

1. **orderId**:

   ```
   Long orderId;
   ```

   Идентификатор заказа, для которого создаётся платёж. Это поле позволяет связать платёж с конкретным заказом в системе.

2. **amount**:

   ```
   Long amount;
   ```

   Сумма, которую нужно оплатить. Это поле указывает, сколько средств должно быть списано с клиента.

---

### \#Резюме:

`PaymentRequest` -- это неизменяемый тип данных, который используется для передачи информации о платёжном запросе. Он содержит два поля: `orderId`, которое связывает платёж с заказом, и `amount`, которое указывает сумму для оплаты. Этот класс служит для передачи данных при создании нового платежа в системе.

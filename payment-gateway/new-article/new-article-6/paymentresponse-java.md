Этот класс представляет собой тип данных для ответа на запрос о платеже. Он используется для передачи информации о платеже, такой как его идентификатор и текущий статус.

#### \#Пакет:

```
package com.example.payment.gateway.dto;
```

#### \#Описание:

`PaymentResponse` -- это тип данных `record`, который был введён в Java 14 для упрощения создания неизменяемых объектов. Этот класс содержит два поля: `paymentId` и `status`, которые используются для возврата информации о платёжной операции после её обработки.

---

### \#Поля:

1. **paymentId**:

   ```
   Long paymentId;
   ```

   Идентификатор платежа. Это поле указывает уникальный ID, который присваивается платежу в системе.

2. **status**:

   ```
   PaymentStatus status;
   ```

   Статус платежа. Это поле содержит текущее состояние платежа, которое представлено перечислением `PaymentStatus` (например, `INIT`, `AUTHORIZED`, `CAPTURED` и так далее).

---

### \#Резюме:

`PaymentResponse` -- это неизменяемый тип данных, который используется для возврата информации о платёжной операции. Он включает в себя два поля: `paymentId`, который представляет уникальный идентификатор платежа, и `status`, который показывает текущее состояние этого платежа. Этот класс удобен для передачи данных в ответ на запросы, связанные с платежами.

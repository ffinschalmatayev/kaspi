Этот класс представляет собой сервис для обеспечения идемпотентности операций в платежной системе. Он используется для предотвращения повторной обработки одинаковых запросов с одинаковыми уникальными ключами.

#### \#Пакет:

```
package com.example.payment.gateway.service;
```

#### \#Импорты:

```
import org.springframework.stereotype.Service;

import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;
```

#### \#Аннотация:

-  `@Service`: Указывает, что этот класс является сервисом, который будет автоматически зарегистрирован в контексте Spring и доступен для внедрения в другие компоненты.

---

### \#Поля:

1. **cache**:

   ```
   private final Map<String, Object> cache = new ConcurrentHashMap<>();
   ```

   Это потокобезопасная карта (используется `ConcurrentHashMap`), которая хранит уникальные ключи и результаты их обработки. Используется для хранения данных, чтобы избежать повторной обработки одинаковых запросов с одним и тем же ключом.

---

### \#Методы:

1. **isProcessed(String key)**:

   ```
   public boolean isProcessed(String key) {
     return cache.containsKey(key);
   }
   ```

   Этот метод проверяет, был ли уже обработан запрос с данным уникальным ключом. Если ключ присутствует в `cache`, то возвращается `true`, что означает, что операция была уже выполнена.

2. **register(String key, Object result)**:

   ```
   public void register(String key, Object result) {
     cache.put(key, result);
   }
   ```

   Этот метод регистрирует результат обработки запроса, ассоциируя его с уникальным ключом. После того как операция выполнена, её результат сохраняется в `cache`.

3. **getResult(String key)**:

   ```
   public Object getResult(String key) {
     return cache.get(key);
   }
   ```

   Этот метод возвращает результат, ассоциированный с уникальным ключом, если такой результат был зарегистрирован.

---

### \#Резюме:

`IdempotencyService` -- это сервис, который обеспечивает идемпотентность запросов. Он использует потокобезопасную карту для хранения результатов обработанных запросов. С помощью этого сервиса можно предотвратить повторное выполнение одинаковых операций, что важно в финансовых приложениях, где повторные операции могут привести к ошибкам или избыточным транзакциям.

Этот класс представляет собой компонент, который проверяет, является ли сумма платежа подозрительной (например, из-за её размера). Он использует значение порога, которое можно настроить через файл конфигурации.

#### \#Пакет:

```
package com.example.payment.gateway.service;
```

#### \#Импорты:

```
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;
```

#### \#Аннотация:

-  `@Component`: Указывает, что этот класс является компонентом Spring, который будет автоматически зарегистрирован в контексте приложения и доступен для внедрения.

---

### \#Поля:

1. **threshold**:

   ```
   @Value("${payment.fraud.threshold:900000}")
   private long threshold;
   ```

   Это поле содержит пороговое значение для суммы платежа, выше которого платеж будет считаться подозрительным. Значение порога можно настроить через файл конфигурации (например, `application.properties` или `application.yml`). Если настройка отсутствует, будет использоваться значение по умолчанию -- `900000`.

---

### \#Метод:

1. **isSuspicious(long amount)**:

   ```
   public boolean isSuspicious(long amount) {
     return amount > threshold;
   }
   ```

   Этот метод проверяет, является ли сумма платежа подозрительной, сравнивая её с пороговым значением. Если сумма больше порога, метод возвращает `true`, что означает, что платеж считается подозрительным. В противном случае возвращается `false`.

---

### \#Резюме:

`PaymentChecker` -- это компонент, который используется для проверки подозрительности платежа по его сумме. Если сумма превышает заданный порог, метод `isSuspicious()` возвращает `true`, что позволяет системе отметить такой платеж как подозрительный, например, для дальнейшей проверки. Пороговое значение можно настроить через конфигурацию, что даёт гибкость в настройках безопасности платежной системы.
